What an AI system actually does

CHATBOTS / RETRIEVAL

Knowledge assistant

Answer questions using approved documents. Retrieval-augmented generation (RAG) finds relevant passages and provides them to the language model.

EXAMPLE INPUT

A staff member asks about a company policy.

EXPECTED OUTPUT

An answer with source references, or a clear handoff when evidence is insufficient.

OCR / EXTRACTION

Document processing

Turn incoming invoices, forms or PDFs into structured records, then validate the extracted fields before updating a business system.

EXAMPLE INPUT

An invoice arrives with a supplier, date and line items.

EXPECTED OUTPUT

A checked record for accounting, or a review task for missing or inconsistent fields.

TOOL CALLS / APPROVALS

AI workflow automation

Classify an incoming request, draft a response or propose an action. Deterministic workflow rules control which actions may run.

EXAMPLE INPUT

A support request needs categorisation and routing.

EXPECTED OUTPUT

A ticket with a proposed category and response; sensitive actions wait for approval.

Evaluate before expanding

QuestionWhat we test
Are answers supported?Check retrieved evidence, source references and behaviour when information is missing.
Are extracted records correct?Compare important fields against labelled examples; review errors by document type.
Are actions controlled?Test approval rules, restricted tools, failed calls and duplicate requests.
Is it practical to run?Measure latency, per-task cost and completion quality on realistic samples.

An AI stack, selected for the task

Model layer

Language-model APIs or suitable hosted/open models for extraction, generation or classification.

Knowledge layer

Embeddings, document chunking and search/vector storage for retrieval-based assistants.

Workflow layer

n8n or Power Automate, Python/JavaScript, business APIs and queues where needed.

Evaluation layer

Reference examples, regression tests, tracing, output validation and reviewer feedback.

Training a custom model is considered only when the task, available data and evaluation justify it.

People are part of the workflow

Skills involved

  • AI application engineering and API integration
  • Retrieval design, document preparation and access filtering
  • Evaluation, error analysis and monitoring
  • Process mapping and exception handling

Back office & BPO

Data entry, customer support and finance/admin work need clear procedures, trained reviewers and quality checks. AI can assist; service responsibilities and review ownership are defined separately.

What you receive

A tested workflow, defined approval rules, evaluation examples and a guide for handling exceptions.
